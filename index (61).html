<HTML Basic Tags/>

What is HTML? — HTML is the standard markup language used to create webpages. Every page you've ever visited is built from tags like these.

1. <html>

Defines the root of an HTML document. Everything else lives inside it.

<html>
  ...
</html>
2. <head>

Contains webpage information that isn't shown directly on the page, like the title.

<head>
  <title>My Page</title>
</head>
3. <body>

Contains everything visitors actually see: text, images, links, buttons, and more.

<body>
  <h1>Hello World</h1>
</body>
